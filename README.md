# 🍽️ Omnifood – Healthy Meals Delivered to Your Door

Omnifood is a modern, responsive food delivery website designed to make healthy eating simple and convenient. It showcases a fictional AI-powered meal subscription service that delivers fresh, nutritious meals directly to customers.

The project is built using HTML5 and CSS3, focusing on clean design, responsive layouts, and an engaging user experience.

## ✨ Features

- **Modern UI:** Clean and attractive website design.
- **Responsive Layout:** Grid-based layout for different screen sizes.
- **Healthy Food Showcase:** Displays a variety of healthy meals.
- **How It Works:** Explains the meal subscription process.
- **Customer Testimonials:** Highlights customer experiences.
- **City Showcase:** Displays the cities where the service is available.
- **Subscription Plans:** Presents different meal subscription options.
- **Contact Form:** Allows visitors to get in touch.

## 🛠️ Technologies Used

- HTML5

## 🚀 Getting Started

Follow these steps to run the project locally:

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Navigate to the project directory:

   ```bash
   cd Omnifood
   ```

3. Open `index.html` in your browser.

   Alternatively, use the **Live Server** extension in Visual Studio Code.
